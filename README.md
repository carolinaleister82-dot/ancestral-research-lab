# Ancestral Research Lab

Personal, non-commercial genealogy research project currently in development.

## Purpose

Ancestral Research Lab is intended to support:

- genealogical investigation and evidence organization;
- structured analysis of people, family and social relationships, facts, events, places, and sources;
- source-aware research notes and documented conclusions;
- authorized integrations with documented genealogy APIs, including the FamilySearch API where applicable.

## Project status

This is an early-stage personal research project. Features, data structures, and documentation may change as development progresses.

## Scope and limitations

The project uses only documented and authorized API capabilities. It does not claim to provide access to, retrieve, download, or redistribute Digital Genealogical Society (DGS) image groups, historical record images, restricted collections, or other content outside those documented API capabilities.

## Non-commercial use

This project is maintained for personal genealogical research and evidence organization. It is not a commercial product and does not sell genealogical data or access to third-party services.

## Privacy and evidence principles

Research should preserve source attribution, distinguish documented facts from hypotheses, and avoid treating inferred relationships as proven without supporting records.
